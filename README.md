# Retail Sales Analysis

## Project Overview

An end-to-end retail sales analysis project exploring transaction data to understand sales performance, product trends, and geographic sales patterns. The project combines Python-based analysis, SQL queries, and business intelligence dashboards to turn retail transaction data into meaningful business insights.

## Project Objectives

- Analyze retail sales performance and revenue trends.
- Identify top-performing products.
- Explore sales patterns across time periods and countries.
- Present analytical results through interactive dashboards and visualizations.

## Tools & Technologies

- **Python — Jupyter Notebook:** Data exploration and analysis.
- **SQL:** Querying retail transaction data and investigating sales trends.
- **Power BI:** Interactive dashboards for visualizing sales performance.
- **Google Sheets:** Supplementary dashboard and data visualization, created with assistance from Gemini.

## Dataset

The project uses retail transaction data containing fields such as:

- Invoice number
- Product code and description
- Quantity
- Invoice date
- Unit price
- Customer ID
- Country

## Analysis Workflow

1. Explore and inspect the retail transaction data.
2. Analyze sales data using Python and Jupyter Notebook.
3. Use SQL queries to investigate retail sales patterns.
4. Develop Power BI dashboards to communicate analytical results.
5. Create a supplementary dashboard in Google Sheets.

## Dashboards & Visualizations
